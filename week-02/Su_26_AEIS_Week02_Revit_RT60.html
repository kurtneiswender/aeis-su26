§ 01

Same Math, Different Source.

The Rhino script reads surfaces from layers named AEIS_<MATERIAL>. The Revit script reads the same information from your Revit model — room volumes come from the Room element, wall areas come from boundary segment lengths, and material assignments come from wall and ceiling type names.

The Sabine and Eyring formulas are identical. The material absorption table is identical. The HTML report is identical. The only difference is where the script finds your geometry and material data.

§ 02

Before You Start.

You need two things: your Revit model with at least one bounded Room element, and the script file. Dynamo is built into Revit — no additional software required.

1

Your Revit model needs a Room

The script reads acoustic data from Revit's Room element. If your model doesn't have one yet, place one now: Architecture tab → Room & Area panel → Room. Click inside your enclosed space. Revit will compute the room's volume automatically from the bounding walls, floors, and ceilings.

The room must be bounded — all four walls, a floor, and a ceiling must close the space or Revit will report a zero-volume room and the script will error. Use the Room Separation Line tool to close open edges if needed.

Volume check: Select your Room and look at the Properties panel. The Volume parameter should read a realistic number — a 500-seat concert hall might be 8,000–15,000 m³. If it shows 0, the room isn't fully bounded.
2

Download aeis_rt60_revit.py

The script is in the course repository. Download python/aeis_rt60_revit.py from the course files on Canvas (or copy it from the instructor's shared drive). Save it somewhere you'll remember — your Desktop or a course folder.

You won't run this file directly. You'll paste its contents into a Dynamo Python node. The file is the source of truth; keep it around for reference and to re-paste when you update your model.

3

Open Dynamo from inside Revit

In Revit: Manage tab → Visual Programming → Dynamo. A new Dynamo window will open. Create a new Dynamo graph (File → New).

Dynamo version matters for the Python engine. Dynamo 2.13+ (ships with Revit 2023+) uses CPython 3 by default. Older versions use IronPython 2.7. The script works with both — if you get a SyntaxError, check your Python engine setting in Dynamo preferences and switch to CPython 3 if available.

A

Add the Python Script node

Right-click on the canvas → Script → Python Script. A node will appear with two input ports by default. You need three. Click the + button at the bottom-left of the Python node to add a third port (IN[2]).

Double-click the Python node to open the editor. Select all the default code and delete it. Paste the entire contents of aeis_rt60_revit.py. Close the editor — the node will show a green checkmark if the script loaded without errors.

Error on paste? Make sure you've deleted all the default stub code before pasting. If you see a Python engine error, open Dynamo Preferences → Python Engine and switch to CPython 3.
B

Wire IN[0] — the Room element

Add a Select Model Element node (Search: "Select Model Element" in the node library). Click the "Select" button on the node, then click your Room in the Revit viewport. The node will show the room's name and number.

Draw a wire from this node's output to the Python node's IN[0] port.

Alternatively, use All Elements of Category → Category: Rooms → then an List.GetItemAtIndex node at index 0 to select the first room. This is useful if your model has multiple rooms and you want to switch between them.

C

Wire IN[1] — program type

Add a String node (Search: "String" → Core → Input → String). Type one of the following program type keys exactly:

"speech" # conference rooms, classrooms — target 0.6–1.0 s "mixed" # multipurpose, lecture halls — target 1.4–1.8 s "music_opera" # opera houses, lyric halls — target 1.6–2.0 s "music_symph" # symphony / orchestral halls — target 1.8–2.2 s "cinema" # film theaters, screening rooms — target 0.3–0.5 s

Wire this node's output to IN[1]. Use the same program type you selected in Week 1 for a direct comparison.

D

Wire IN[2] — HTML report path (optional)

Add a File Path node (Search: "File Path" → Core → Input). Click the folder icon and choose a save location, or type a path directly: C:\Users\you\Desktop\rt60_report.html. Wire to IN[2].

If you leave IN[2] disconnected or wire a String node containing None, the script skips the HTML report and only outputs the text summary to the Watch node.

E

Add a Watch node and run

Add a Watch node from the library. Wire the Python node's output to Watch. Click Run (the triangle button in the Dynamo toolbar, or press F5).

The Watch node will display a formatted text table of RT60 results per octave band. If you wired a report path, the HTML report opens automatically in your browser.

First run successful? Check that the volume number in the report matches your Revit Room's Volume property. If there's a big discrepancy, your room boundary may not be fully closed — see §02, Step 1.
§ 04

Connecting Your Materials.

In Rhino you tagged surfaces by renaming their layer to AEIS_ACOUSTIC_TILE or AEIS_CONCRETE_BARE. In Revit, the equivalent is your wall and ceiling type names. The script looks for keyword substrings inside those type names to assign an absorption coefficient.

This means you don't need to rename anything in Revit — you edit the MATERIAL_MAP list inside the script to match the naming conventions you already used in your project.

Example: If your wall type is named Interior - Gypsum on Stud - 4", the script finds the substring "gypsum" and assigns GYPSUM_BOARD absorption coefficients. If your ceiling type is Acoustic Ceiling Tile 2x2, it matches "acoustic tile" → ACOUSTIC_TILE.

Open the script in any text editor and locate the MATERIAL_MAP list near the top. Each entry is a pair: a substring to look for (case-insensitive), and the material key to assign.

MATERIAL_MAP = [ # ─ Walls ────────────────────────────────────────────────────────── ("gypsum", "GYPSUM_BOARD"), # matches "Gypsum on Stud", "GWB", etc. ("drywall", "GYPSUM_BOARD"), ("cmu", "CONCRETE_BLOCK"), # matches "CMU", "CMU 8-inch" ("masonry", "CONCRETE_BLOCK"), ("concrete", "CONCRETE_BARE"), ("brick", "BRICK"), ("glass", "GLASS"), ("curtain wall", "GLASS"), # ─ Ceilings ──────────────────────────────────────────────────────── ("acoustic tile", "ACOUSTIC_TILE"), ("lay-in", "ACOUSTIC_TILE"), ("cloud", "CEILING_CLOUD"), ("gypsum ceil", "GYPSUM_BOARD"), # ─ Floors ────────────────────────────────────────────────────────── ("carpet", "CARPET_THICK"), ("hardwood", "WOOD_FLOOR"), ("tile", "CONCRETE_FLOOR"), # careful: also matches "acoustic tile" ]

First match wins. Rules are checked top to bottom. Put more-specific substrings before broad ones. Note that "tile" would match "Acoustic Ceiling Tile" — which is why "acoustic tile" appears higher in the list.

If no rule matches a wall or ceiling type, the script falls back to the category default: GYPSUM_BOARD for walls, ACOUSTIC_TILE for ceilings, CONCRETE_FLOOR for floors. These defaults are set near the top of the script.

§ 05

Reading the Report.

The HTML report output is identical in structure to the Rhino RT60 report. The same six-section layout, the same status bar, the same octave-band table. Here's what each section is telling you and where to focus your attention for Act I.

500 Hz Summary
This is your primary result. The Eyring RT60 at 500 Hz is the single number that represents your room's reverberation. Check it against your program target. The status badge reads IN RANGE, TOO DRY, or TOO LIVE.

The Sabine value is the hand-calculation reference — it should be within ~15% of Eyring for rooms with mean absorption below 0.3. A larger gap means your room is highly absorptive; use the Eyring value in your submission.
Status Bar
The horizontal bar shows your 500 Hz Eyring result on a 0–3 s scale. The green zone is your program target range. The needle is your result. If the needle is outside the green zone, your material strategy needs revision — see §06.
Octave Band Table
RT60 values at 125, 250, 500, 1000, 2000, and 4000 Hz. For speech-primary rooms, look at 500 and 1000 Hz most carefully. For music rooms, 125 and 250 Hz bass RT60 matters — it should stay within range or slightly above. A bass RT60 that's much higher than mid-frequency indicates insufficient low-frequency absorption.
Material Schedule
Each surface category, Revit type name, assigned material key, area, α at 500 Hz, NRC, and absorption sabins. Verify this table carefully. If a surface shows an unexpected material key, your type name didn't match any rule — the script used the category default. Add a rule to MATERIAL_MAP to fix it.

The total sabins in the last row is your room's total 500 Hz absorption. Divide by total surface area to get mean α — if mean α is above 0.5, Eyring diverges significantly from Sabine.
Room Parameters
Volume, total surface area, total absorption, and mean α. Volume should match your Revit Room's Volume property. If there's a significant discrepancy, check your room boundaries. Use these numbers in your Act I hand-calculation comparison worksheet.
Footer Note
A reminder of the script's assumptions: wall areas are calculated from boundary segment lengths × room height; ceiling area equals floor area (flat ceiling assumed); window and door areas are not subtracted from wall areas. These simplifications matter most for highly glazed rooms — if your design has significant glazing, note the discrepancy in your Decision Log.
§ 06

Comparing Rhino and Revit Results.

If you ran both the Rhino and Revit scripts on the same room, you may see slightly different RT60 values. That's expected — here's how to interpret the differences.

If the Revit result is… Most likely reason What to do
Within ±0.2 s of Rhino Normal modeling tolerance — surface area approximations and bounding box vs. solid volume differ slightly. No action needed. Use the Revit result if Revit is your primary model.
Significantly higher (longer) than Rhino Revit is assigning less-absorptive materials — likely a MATERIAL_MAP match failure falling back to defaults. Check the Material Schedule. Find surfaces with unexpected material keys. Add matching rules.
Significantly lower (shorter) than Rhino Revit wall area is larger than Rhino (boundary segment count is higher, or room height differs). Or Revit assigned a more-absorptive ceiling type. Verify room height in Revit matches Rhino model. Check ceiling type assignment.
Volume is wrong Room element isn't fully bounded. Open edges, or ceiling/floor elements not framing the room. Use Room Separation Lines to close open boundaries. Verify Room.Volume in Revit properties.
For your Act I submission, you only need one RT60 analysis — Rhino or Revit, not both. But if you ran both, comparing them is excellent material for your Decision Log. Note the discrepancy, explain the cause, and state which result you trust and why.
§ 07

Your Result is Out of Range.

The script's job is to tell you the truth about your current design. If the result is outside your program target, that's the assignment working — you now have a diagnostic and a design problem to solve.

↑

RT60 too long — room is too live

The fix is more absorption. Look at your largest surfaces first — walls (highest area) make the biggest per-change impact. Switching a concrete wall type to gypsum board adds moderate absorption. Adding acoustic tile ceiling coverage or fabric panels adds significant absorption in mid-high frequencies.

In Revit: change the wall or ceiling type. In your MATERIAL_MAP, confirm the new type name maps to a more absorptive key. Re-run the Dynamo script. The HTML report will update.

For bass frequencies (125–250 Hz) that are still too live: add BASS_TRAP or ACOUSTIC_PANEL surfaces — these are thick fabric-wrapped panels. You'd need to model them as additional surface elements in Revit or manually add their area to the script's surface data.

↓

RT60 too short — room is too dry

The fix is less absorption or more volume. If you have acoustic tile ceilings everywhere, consider reducing ceiling coverage or switching portions to hard plaster or GRC panels. If you have heavy carpet, consider hard flooring in non-seating areas.

Volume also matters directly — Sabine RT60 = 0.161 × V / A. If your room volume is small relative to the absorption, add volume (raise the ceiling, add fly space above the stage). Document this in your Decision Log: "I added X m³ of volume to bring 500 Hz RT60 from Y to Z."

Each design iteration is a Decision Log entry. Log the before RT60, what you changed (material or geometry), and the after RT60. Three to five iterations is a credible acoustic design process for Act I.
§ 08

Act I Deliverable.

Act I is due Tuesday 06·10 at 11:59 PM on Canvas. The submission has two parts: a PDF package and a pasted Decision Log text entry. This Revit workflow contributes to both.

Acoustic Plan + Section from Revit

Export a plan and at least one section from Revit showing your room geometry. Tag surface materials with a legend. If you ran the script, the Material Schedule table shows which type name mapped to which absorption key — use that as your legend source.

RT60 Report (HTML → PDF)

Open your saved HTML report in Chrome. Print → Save as PDF. Include this in your PDF package. The report's Material Schedule and octave-band table are your primary technical evidence. You can use either the Rhino or Revit report — or both, if you're comparing them.

Hand calculation at 500 Hz (Sabine)

The Sabine value in the report is your hand-calculation reference. Reproduce the calculation by hand or in a spreadsheet: RT60 = 0.161 × V / Σ(αᵢ × Aᵢ). Your result should match the script's Sabine value within ±0.1 s. Include this worksheet in the PDF.

Acoustic deficiency identification

State whether your design is IN RANGE, TOO DRY, or TOO LIVE, and which frequency bands are most problematic. The octave-band table gives you this directly. Reference at least two specific octave bands.

Material correction strategy

If your result was out of range, describe the change you made (material substitution or volume adjustment), show the revised RT60, and explain why the change worked acoustically. If you're in range, explain which material choices drove you there.

Decision Log entries (Weeks 1–3) — pasted as text

Copy your Decision Log entries from Weeks 1, 2, and 3 and paste them into the Canvas text field. The log should document your material reasoning, your RT60 results at each iteration, and what you changed between runs. Entries from this Revit workflow (if used) count toward Week 2 and Week 3 log entries.
